# Superseded Localized-Eye Portal

This package preserves the rejected 12-frame portal revision where only a compact circular eye rotated and the surrounding portal stayed static. It also preserves that revision's procedural far-field FX processor, runtime sheets, generated sources, and review exports.

Owner review requires generated full-surface multilayer vortex motion, an animated/deforming rim, more frequent lightning around the complete circumference, and a smaller runtime scale. Nothing in this package may be referenced by active runtime resources.

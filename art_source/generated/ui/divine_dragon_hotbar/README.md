# Divine dragon hotbar source

The transparent `dragon_hotbar_source.png` was generated on 2026-09-27 after the owner clarified that the action bar needed actual godlike edge artwork and a redesigned Space icon. The sheet contains opposing divine-dragon reliefs and a matching winged-claw Dash glyph. It is source art, not a Godot runtime texture.

Prompt: "Create a production concept SOURCE SHEET of pixel-art UI ornaments for a dark-fantasy Godot action RPG called Battle of Gods. Transparent background with real alpha. Three clearly separated, non-overlapping objects with wide transparent gutters: (1) LEFT end ornament, a regal divine dragon head and angular wing/claw curling inward to hold the left end of a horizontal combat hotbar; (2) RIGHT end ornament, an exact horizontal mirror design of the same dragon relief, not a different creature; (3) a compact square SPACE/DODGE emblem showing one decisive winged step or dragon-claw dash, as a strong single silhouette. The dragon should feel like a carved god relic or sacred tattoo, majestic and ancient, not demonic, no skulls or flames. Pixel art made from intentional hard rectangular pixels: crisp 1-2-pixel dark navy outline, carved ivory-white highlights, weathered relic gold, sparse spirit-cyan edge light, tiny restrained violet rune accents. Maximum 14-color palette, flat color clusters, upper-left light, no gradients, no anti-aliasing, no painterly effects, no photorealism, no excessive filigree. Bold forms must read when each ornament is shrunk to about 54x52 logical pixels and the dash emblem to 24x24. Orthographic 2D game asset view. Absolutely no text, letters, numerals, buttons, bar, interface mockup, background, watermark or border around the entire sheet."

`tools/build_divine_dragon_hud_art.gd` crops the approved left relief and Dash glyph, maps both to the fixed fourteen-color UI palette, thresholds alpha, removes isolated pixels, and mirrors the left relief for an identical right edge. Runtime assets live under `assets/ui/hud/divine_dragon/`. The dragons decorate only the HUD; they do not establish a god's lore emblem.

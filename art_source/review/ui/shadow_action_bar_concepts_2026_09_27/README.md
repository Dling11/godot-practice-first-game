# Shadow action-bar concepts — owner review

These are generated full-box concepts. Neither original concept image is a Godot runtime asset because both bake in icons and labels. The owner selected Eclipse Bind (B), which was then adapted into an empty frame and installed behind live controls. The earlier dragon reliefs are no longer referenced by active scenes.

- `shadow_crown_concept.png`: shadow-forged crown frame, obvious grasping hands, stronger/taller silhouette.
- `eclipse_bind_concept.png`: selected lower living-shadow frame, integrated corners and eclipse, quieter visual footprint.

Both concepts preserve the functional order: Space/Dodge, ten equipped skills on 1–9/0, then Attack. Eclipse Bind's installed version uses `art_source/generated/ui/eclipse_bind_hotbar/` as source and `assets/ui/hud/eclipse_bind/` at runtime. Text, slots, charge badges, cooldowns and pointer targets are real Godot UI over the pixel-clean frame. The grounded Dash sound remains a separate audio asset.
